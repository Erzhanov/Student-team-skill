Промт:«Создай прототип формы добавления учебника на чистом HTML, CSS и JavaScript.

Требования к форме:

Поле ввода названия учебника (обязательное, валидация на непустую строку с обрезкой пробелов).

Выпадающий список выбора состояния книги: «Новое», «Отличное», «Хорошее», «Требует ремонта» (значение по умолчанию не выбрано, выбор обязателен).

Блок для вывода понятного сообщения об ошибке при попытке некорректной отправки.

Блок подтверждения отправки с отображением введенных данных.

Обработка отправки через JavaScript без перезагрузки страницы (эмуляция сохранения).

Стили сделай аккуратными, современными и компактными.»
